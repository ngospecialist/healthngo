# Contributing to HealthNGO

Thank you for your interest in improving HealthNGO's digital presence.

## Ways to contribute

- Improve project documentation.
- Suggest accessible and mobile-friendly website improvements.
- Help organize awareness resources.
- Report factual errors, broken links, or accessibility issues.
- Suggest responsible social media and community engagement ideas.

## Before submitting a change

1. Check existing issues and pull requests to avoid duplicate work.
2. Keep suggestions respectful, clear, and relevant to the NGO's stated purpose.
3. Use plain language and accessible formatting.
4. Verify factual statements and cite trustworthy sources where appropriate.
5. Do not include confidential or personally identifying information.

## Pull request guidelines

- Give your pull request a descriptive title.
- Explain what changed and why.
- Include screenshots for visual website changes, when relevant.
- Mention any testing performed.
- Keep changes focused and easy to review.

## Content and privacy

Never upload beneficiary names, phone numbers, addresses, medical records, identity documents, private conversations, or photographs without appropriate informed consent and authorization.

Thank you for helping make this project clearer, safer, and more useful.
