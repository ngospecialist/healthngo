# Security Policy

HealthNGO takes the safety and privacy of its community seriously.

## Reporting a vulnerability

Please do not publish exploitable security vulnerabilities, credentials, private data, or sensitive screenshots in public issues.

Contact the project maintainers privately using an official security contact address (to be added by the maintainers). Include:
- A short description of the issue.
- Steps to reproduce, if safe to provide.
- Potential impact.
- Any suggested mitigation.

## Security practices for future website development

- Never commit passwords, API keys, payment secrets, or database credentials.
- Use environment variables or a secure secrets manager.
- Keep dependencies and server software updated.
- Use HTTPS and secure authentication.
- Apply least-privilege access to admin accounts.
- Validate and sanitize user input.
- Collect only the personal data that is genuinely necessary.
- Define retention, consent, and deletion procedures before collecting user information.
- Do not store sensitive medical or beneficiary information unless there is a justified need and appropriate safeguards.

## Scope

This policy applies to the code and documentation maintained in this repository. No service-level security guarantee is implied.
